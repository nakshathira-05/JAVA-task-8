# JAVA-task-8
Payment Gateway Simulator - Java
 Task 8: Interfaces & Abstraction
This project demonstrates a simple Payment Gateway Simulator using Java interfaces and abstraction.

 Features
Payment interface design
Multiple payment modes (Card, UPI, NetBanking)
Abstraction and loose coupling
Dynamic payment switching
Multiple inheritance using interfaces
Invalid payment handling
Discount logic
Logging support
🛠 Technologies
Java
IntelliJ IDEA / Eclipse
